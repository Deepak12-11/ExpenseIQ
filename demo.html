Secure MySQL Database Setup

To run this project with full PHP/MySQL stack:

  1. Start Apache and MySQL in XAMPP or Laragon.
  2. Open http://localhost/phpmyadmin.
  3. Import database.sql from this project folder.
  4. Place this project folder into htdocs and visit http://localhost/expense-tracker.
🔒 Data Leakage Prevention: Scoped user IDs, CSRF tokens, secure session cookies (HttpOnly, SameSite=Lax), and parameterized queries protect all financial data.
